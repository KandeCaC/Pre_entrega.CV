# Pequeños Creadores 🎨✨

Sitio web educativo para niños, con juegos didácticos, imágenes coloridas y tipografías divertidas.  
El proyecto está desarrollado únicamente con **HTML y CSS**.

## 📂 Estructura del proyecto
- `index.html` → Página principal
- `styles/style.css` → Estilos en CSS
- `imagenes/` → Carpeta con imágenes y recursos gráficos


## 💡 Objetivo
Crear un espacio digital interactivo y visualmente armónico para que los niños aprendan jugando.
